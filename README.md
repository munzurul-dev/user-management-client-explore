# User Management Client

A simple User Management application built with React.js.

## Features

- View all users
- Add new users
- Fetch users from Express.js API
- Responsive user interface
- React Router integration

## Technologies

- React.js
- Vite
- Tailwind CSS
- React Router
- Fetch API

## Run Locally

```bash
npm install
npm run dev

The application will run on the Vite development server.
